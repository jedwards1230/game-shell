Input name (config.toml)

The OSD device name this box announces on the CEC bus — the input label TVs/AVRs display. Currently {{ osd_effective }} ({{ osd_source }}). Empty = use the hostname. Max 13 ASCII characters (libcec limit). Saving writes [cec].osd_name in config.toml; restart tv-shell-input (Services page) to announce the new name. Note: other CEC-capable apps that grab the adapter (e.g. Plex HTPC with CEC enabled) announce their own name — keep CEC disabled in apps so the daemon stays the single CEC owner.
